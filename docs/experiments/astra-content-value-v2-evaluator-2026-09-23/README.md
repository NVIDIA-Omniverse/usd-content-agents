# Independent evaluator core: public companion

This is a code, contract, provenance and preparation-evidence supplement to the
v2 preregistration. It contains no scored outcomes, author submissions, model
transcripts or geometry payloads. This companion publishes inspectable evaluator
code and bounded preparation evidence; it is not a scored-results bundle.

Run `python3 -B verify_evaluator_bundle.py .` to check the exact membership,
published byte digests, syntax and the pinned publication privacy scanner.
`publication_manifest.json` distinguishes exact original files from locator-only
JSON projections. Original retained hashes attest the independently frozen
originals; projected bytes cannot verify those original hashes. The global freeze
lists retained-only evidence as well as supplied files; it does not imply that
every listed byte is included here. Do not pass the projected freeze off as the
original experiment authority.

All selected evaluator Python files remain byte-identical. Harmless canonical
`/opt/astra-content-value-*` installation defaults are preserved, as in the
preregistration. Use explicit CLI path overrides, especially the v2 solver Python.
No scoring thresholds, statuses, numerical observations or algorithms changed.
`PRIVACY_PROJECTIONS.json` records JSON-pointer diffs and original-value digests.
Three narrow public-field exceptions preserve the source's public commit message
and the qualification authorization-required boolean; no private messages or
authorization credentials are included.

The frozen drawer README and lineage, importer provenance and environment pins
retain historical unfrozen/development labels. Those describe preparation-time
documents. The original final global freeze and its qualification receipts are
authoritative; this wrapper explains the history without rewriting frozen bytes.

## Scope and missing replay dependencies

The bundle supplies every planned core file, including all case code/contracts,
public tasks and source/reference inventory hashes, plus compact positive and
negative qualification evidence. Failed preparation findings remain visible.
Synthetic qualifications are observer controls, not evidence that an authored
submission passed. Local syntax/privacy verification is not a new physics run.

**No complete ten-case replay is claimed.** EXCLUDED_GEOMETRY.json names all
omitted NPZ/glTF/bin/intermediate USD references and their original digests.
Replay also needs the exact original source closure and a separately retained
submitted USD/bindings/dependency closure. Never substitute alternative geometry.
The trusted orchestration helpers also use the existing preregistration harness;
this supplement is not a stand-alone worker installation.

Only cases03/05 have qualified fresh byte-identical reference regeneration:
03 needs the retained exact-SHA-multiset alignment for random Trimesh primitive
IDs; all13 case05 NPZ files matched, but its redistribution restriction remains.
Case08 is relative to a saved80-mesh converter output, not proven native CAD or
mate completeness. Case10's preceding nine-component inventory was not found
among extracted retained files; the cached69-shell final reference is not a
qualified full fresh rebuild. The separate reproduction supplement documents
remaining cases, saved FreeCAD extraction limits and explicit role choices.
Historical rebuild helpers are not scoring code or new author inputs.

The source-clear drawer initialization and subsequent measurement corrections
are documented; no solved capstone asset is supplied as a fixture or author input.
Drawer geometry checks use original glTF/bin; display textures need their own
source closure. Independent evaluation needs no model or API credentials.
Keep structural OpenUSD/OCP parsing separate from the pinned OvPhysX runtime,
and preserve the published resource limits, seeds, deadlines and verdict rules.

## Attribution and licensing exclusions

SOURCE_NOTICES.json preserves each publisher's source URL, commit, attribution,
license declarations and unresolved provenance. It is a record of those facts,
not newly resolved permission. Independent evaluator code follows the destination
Apache-2.0 project process. CAD/reference data must retain its own license.

Case05 has a README MIT declaration but no linked LICENSE, with separately
branded drawings. Case06 has repository MIT versus native All-rights-reserved
metadata. Their original and derived geometry, rendered images and NPZ arrays
remain excluded pending clarification. Their code/contracts/descriptive
inventories and hashes remain inspectable. Other geometry releases require
recorded license notices, attribution, modification notices and applicable
ShareAlike/source conditions; third-party component provenance is not cleared.

Raw model/session content, secrets, worker configuration, binary runtimes,
archives, cores and caches are excluded. This companion does not supply a complete
source/reference/submission closure or establish comparative performance.
